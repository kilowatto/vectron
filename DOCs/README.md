## Quick start for agents / Inicio rápido para agentes

1. Read **24-coordination-hub.md** first — who owns what, active zones, advance log.
2. Read **01-collaboration-rules.md** before writing code.
3. Read **02-master-plan.md** before changing product direction; **21-remediation-master-plan.md** is the operative plan (F1→F4).
4. Check **archive/** so you do not reinvent or destroy existing work.
5. Follow **00-docs-management.md** when you add or change documentation.

**EN:** Product names are always **Principiante / Intermedio / Avanzado** (Beginner / Intermediate / Advanced). Three distinct apps. Avanzado’s ceiling is **PhD / data-science rigor**.

**ES:** Los nombres de producto son siempre **Principiante / Intermedio / Avanzado**. Tres apps distintas. El techo de Avanzado es **rigor PhD / ciencia de datos**.
