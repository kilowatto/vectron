## Locked naming / Nombres cerrados

**EN:** Product names are always **Principiante / Intermedio / Avanzado** (Beginner / Intermediate / Advanced). Three distinct apps. Avanzado’s ceiling is **PhD / data-science rigor**.

**ES:** Los nombres de producto son siempre **Principiante / Intermedio / Avanzado**. Tres apps distintas. El techo de Avanzado es **rigor PhD / ciencia de datos**.

## Product one-liner / En una frase

**EN:** Vectron is a public 3D meaning-map that teaches how models turn words into vectors — three apps under Principiante / Intermedio / Avanzado.

**ES:** Vectron es un mapa 3D público del significado que enseña cómo los modelos convierten palabras en vectores — tres apps bajo Principiante / Intermedio / Avanzado.
